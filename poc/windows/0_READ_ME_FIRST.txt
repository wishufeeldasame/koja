koja 테스트 방법 (윈도우)
================================

이 테스트는 이 컴퓨터에서 "영상 → 받아쓰기 → 화자 구분 → 일본어 번역"이
제대로, 얼마나 빨리 돌아가는지 확인합니다. 하라는 대로 더블클릭만 하면 됩니다.


■ 준비물
  - NVIDIA 그래픽카드가 있는 컴퓨터 (예: RTX 3060 Ti, RTX 3080)
  - 인터넷 연결
  - C 드라이브에 빈 공간 90GB 이상 (프로그램·모델 약 28GB + 영상 약 27GB + 여유)
  - 테스트용 영상 3개(.MP4)와 sheet.xlsx (따로 받은 파일)
  - 시간: 설치 30분~1시간, 테스트 1~4시간 (컴퓨터 성능에 따라 다름, 예상치)


■ 1. 압축 풀기
  1) 받은 koja-windows-test.zip 파일을 마우스 오른쪽 버튼으로 누르고 [속성]을 엽니다.
     아래쪽에 [차단 해제] 칸이 있으면 체크하고 [확인]을 누릅니다. (없으면 그냥 넘어갑니다)
  2) 다시 오른쪽 버튼 → [압축 풀기] 또는 [모두 압축 풀기]를 누릅니다.
  3) 압축 풀 위치를  C:\  로 바꿉니다.
     → C:\koja-test 폴더가 생기면 됩니다.

  ※ 바탕화면이나 문서 폴더에 풀지 마세요. OneDrive가 수십 GB를 인터넷에 올리려고 해서 느려집니다.


■ 2. 영상과 시트 넣기
  C:\koja-test\samples 폴더를 열고, 영상 3개와 sheet.xlsx 를 그 안에 복사합니다.


■ 3. 설치 (한 번만)
  1) C:\koja-test 폴더의  1_setup.bat  을 더블클릭합니다.
  2) 파란 창 "Windows의 PC 보호"가 뜨면 → [추가 정보] → [실행]을 누릅니다.
     "보안 경고" 창이 뜨면 → [실행]을 누릅니다.
  3) 검은 창이 뜨고 필요한 파일(약 28GB)을 내려받습니다. 창을 닫지 말고 기다립니다.
  4) "설치가 끝났습니다"가 보이면 아무 키나 눌러 창을 닫습니다.

  ※ 중간에 인터넷이 끊기거나 창을 닫았어도 괜찮습니다. 1_setup.bat 을 다시 더블클릭하면 이어서 받습니다.


■ 4. 테스트 실행
  1) 게임, 영상 편집처럼 그래픽카드를 많이 쓰는 프로그램을 모두 끕니다.
  2)  2_run_test.bat  을 더블클릭합니다. (파란 창이 뜨면 3번과 똑같이 [추가 정보] → [실행])
  3) [1/11], [2/11] ... 순서로 진행됩니다. 컴퓨터를 끄지 말고 기다립니다.
     (테스트 중에는 컴퓨터가 절전 모드로 들어가지 않습니다)
  4) "모든 테스트가 끝났습니다"가 보이면 아무 키나 눌러 창을 닫습니다.

  ※ 중간에 멈췄거나 창을 닫았으면 2_run_test.bat 을 다시 더블클릭하세요. 끝난 단계는 건너뛰고 이어서 합니다.


■ 5. 결과 보내기
  C:\koja-test\RESULT_send_this.txt  파일 하나만 보내 주세요.
  이 파일에는 숫자(걸린 시간, 메모리 사용량, 점수)만 들어 있습니다.

  ※ 영상, sheet.xlsx, eval 폴더 안의 파일은 출연자 발언 내용이 들어 있으므로
    다른 곳(메신저, 메일, AI 서비스 등)으로 보내지 마세요.


■ 문제가 생겼을 때
  - 창에 빨간 글씨나 "!!!!" 로 둘러싼 안내가 나오면: 안내대로 한 뒤 같은 bat 파일을 다시 실행합니다.
  - "NVIDIA 그래픽카드를 찾지 못했습니다" / "드라이버가 오래됐습니다":
      https://www.nvidia.com/ko-kr/drivers/ 에서 드라이버를 최신으로 설치하고 컴퓨터를 다시 켠 뒤 다시 실행합니다.
  - "디스크 공간이 부족합니다": C 드라이브의 필요 없는 파일을 지우고 다시 실행합니다.
  - 그래도 안 되면: 검은 창 화면을 사진(또는 캡처)으로 찍고, RESULT_send_this.txt 가 있으면 함께 보내 주세요.


■ 다 끝난 뒤
  다시 테스트할 수도 있으니, 지워도 된다는 연락을 받기 전까지 C:\koja-test 폴더는 그대로 둡니다.
