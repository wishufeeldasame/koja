# koja

게임 인터뷰·리뷰 영상의 한국어 대사를 타임라인·화자와 함께 받아 적고, 일본어로 번역해 Google 시트로 정리하는 데스크톱 앱.

영상 편집자가 시트에서 문장을 복사해 한국어·일본어 자막에 바로 쓰는 것이 목표다.

사람이 영상을 처음부터 끝까지 보며 받아 적던 초기 작업을 줄이는 **초벌 기록** 도구다. 발언을 빠짐없이 기록하는 것이 먼저이고, 무엇을 쓸지 고르고 다듬는 일은 편집자가 앱에서 한다.

> **상태: M1(앱 뼈대) 진행 중.** 영상을 가져와 검수용 프록시와 STT용 오디오를 만들고, 검수 화면을 더미 데이터로 띄울 수 있다. 실제 전사·번역은 아직 없다. 진행 상황은 [로드맵](#로드맵)을 본다.

## 하는 일

1. 영상 파일 하나를 불러온다.
2. 한국어 발화를 받아 적는다. 발화 시작 시각(`분:초`)과 화자도 함께 기록한다.
3. 영상 유형을 판별해 행을 구성한다.
   - 일본인 인터뷰어: 일본어 질문은 별도 질문 영역에 둔다
   - 한국인 인터뷰어: 질문을 일반 행으로 두고 노란색으로 표시한다
   - 자유 발언형: 질문/답변 구조를 만들지 않는다
4. 일본어로 번역한다. 발로란트 용어집을 반영한다.
5. 화자를 확인할 수 없거나 내용이 들리지 않는 행에 검수 표시를 단다.
6. 앱 화면에서 영상과 대사 표를 나란히 놓고 검수한다. 행을 누르면 그 시점으로 이동한다.
7. Google 시트로 내보낸다. 열은 タイムライン / 話者 / 韓国語 / 日本語.


## 지원 환경

| OS | 확인 대상 장비 | 로컬 AI 가속 |
|---|---|---|
| Windows 10/11 x64 | Ryzen 7 5800X3D + RTX 3060 Ti 8GB / RTX 3080 10GB, RAM 32GB 이상 | CUDA |
| macOS (Apple Silicon) | M5 Pro 24GB | Metal |

AI 단계(음성 인식, 화자 구분, 구조화·번역, 화면 분석)마다 **로컬** 또는 **외부 API**를 고를 수 있게 만든다. 로컬을 먼저 구현한다.

## 구조

```
JavaFX 앱
 ├─ 가져오기  ffmpeg → 오디오(16kHz) + 검수용 MP4
 ├─ STT       로컬 엔진 (M0에서 결정) / 외부 API
 ├─ 화자 구분  로컬 엔진 (M0에서 결정) / 외부 API
 ├─ 구조화·번역 llama.cpp llama-server (내장) / 외부 LLM
 ├─ 검수 화면  영상 + 편집 가능한 표
 └─ 내보내기   Google Sheets API (사용자 구글 계정 OAuth)
```

핵심 원칙: 타임라인과 한국어 원문은 음성 인식 결과에서만 나온다. LLM은 시간이나 원문을 만들지 않고, 구간을 묶고 분류하고 번역만 한다.

자세한 설계: [docs/설계.md](docs/설계.md) · 결정과 이유: [docs/결정기록.md](docs/결정기록.md) · 변경 이력: [CHANGELOG.md](CHANGELOG.md)

## 기술스택

- Java 25 LTS · JavaFX · Gradle · jpackage (.msi / .dmg)
- ffmpeg, llama.cpp `llama-server` 내장
- Google Sheets API v4, OAuth Desktop (`drive.file` 스코프)
- 빌드: GitHub Actions에서 Windows·macOS 각각 빌드

## 개발

맥에서 개발한다. 윈도우 CUDA 경로는 맥에서 테스트할 수 없으므로 윈도우 실기에서 확인한다.

```bash
./gradlew run
```

가져오기에는 ffmpeg가 필요하다. 개발 중에는 `PATH`의 `ffmpeg`를 쓰고, 다른 것을 쓰려면 환경 변수 `KOJA_FFMPEG`에 경로를 준다. 설치판에는 LGPL 빌드를 넣을 예정이다(D-037).

JDK 17 이상이 있으면 된다. JDK 25는 첫 빌드 때 Gradle이 받아 온다(인터넷 연결 필요). 나머지 명령은 [AGENTS.md](AGENTS.md#빌드실행테스트).

작업 규칙: [AGENTS.md](AGENTS.md). Claude Code, Codex, OpenCode/oh-my-opencode, Antigravity 모두 이 파일을 읽는다.
